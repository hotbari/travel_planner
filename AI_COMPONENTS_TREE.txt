Component States

AIModeSelector:
  - default: Both buttons inactive style
  - optimize_only: Left button active (gradient + corners)
  - suggest_and_optimize: Right button active (gradient + corners)

AIOptimizeButton:
  - idle: Gradient + shimmer effect
  - loading: Spinner + "Optimizing..." + no shimmer
  - error: Inline error box below button
  - disabled: Muted colors + no interactions

AISuggestionCard:
  - unselected: Slate border + hover glow
  - selected: Sky blue border + shadow + checkmark + corners
  - hover: Subtle background gradient

AIPreviewPanel:
  - closed: Not rendered
  - opening: Backdrop fade + panel slide from right
  - open: Fully visible, interactive
  - closing: Reverse animation
